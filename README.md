BACK CLIENT



BACK CLIENT is a Minecraft Java launcher for Windows, developed in Python.



Features

Graphical interface for managing Minecraft versions and profiles.

Microsoft account authentication for eligible Minecraft: Java Edition owners.

Local profile mode for compatible environments.

Launcher settings and profile management.

Authentication and security



The launcher is intended to use Microsoft's official sign-in flow and the required Minecraft authentication services. Users should never share their Microsoft passwords or authentication tokens.



Purpose



This project is being developed to provide a simple, modern launcher interface while respecting Microsoft and Minecraft authentication requirements.
